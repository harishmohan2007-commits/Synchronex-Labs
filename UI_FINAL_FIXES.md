# Synchronex final UX fixes

- Fixed portal handoff blank-screen state by resetting the landing screen whenever authentication succeeds.
- Company login now always opens Command; Field login always opens Field Home.
- Schedule no longer renders the redundant "Select a discipline" section below discipline cards.
- Schedule discipline cards use one consistent surface and status is expressed through a restrained accent rather than different card surfaces.
- Removed the detached settings trust panel from the bottom of Settings.
- Hid native file inputs in Import so browser "Choose files" controls cannot leak outside the designed cards.
- Strengthened dark/system theme surface and text tokens so cards, tables, selects, activity rows, memory and import content remain readable.
- Kept schedule activity detail, review flow, memory occurrence detail, company/field portals, team management and settings functionality intact.
