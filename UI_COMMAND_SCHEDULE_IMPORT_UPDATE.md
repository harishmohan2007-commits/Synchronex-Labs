# Command, Schedule and Import UX Update

Updated the active `src/App.tsx` and `src/index.css` with the latest requested UI changes:

- Command page keeps the title but removes the command breadcrumb/subtitle, execution-mode indicator, nearby schedule action, recent execution-signal section, project-health card, and incoming-evidence card.
- The Project Pulse graph expands to the full main content area.
- The command sidebar keeps the decision queue and adds a compact Control Focus panel so removed space is useful.
- Schedule discipline cards no longer show milestone/evidence footer text, and dark-theme surfaces are unified for readability.
- Company Import is now focused on approved schedule intake. The old evidence-import section and the obsolete lower intake/pipeline content are removed.
- The Import page uses a full-width schedule intake card with a dropzone, validation action, and pre-publish mapping panel.
